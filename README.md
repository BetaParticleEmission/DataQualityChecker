# DataQualityChecker

## Goal: 
The goal of the project is to develop a dataquality checker class that can take a dataset as an input. \
By using streamlit with OOP in Python, a dashboard can be made to analysis the data quality of the dataset. \
The data quality checks include: completeness, consistency, accuracy, timeliness, and uniqueness. 

## How to use: 
The dataset that is currently used as a placeholder is "Tips". Replace the Tips dataset with a dataset of your choice. \
In order to run the file, open the terminal and execute the command: "streamlit run DataQualityChecker.py".
Open each of the streamlit dataframes to gain an understanding of the "cleanliness" for the dataset.
